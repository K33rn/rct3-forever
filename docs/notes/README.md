# Notes on RCT3plus.exe, by subsystem

What each function does, worked out by studying the program: what it calls and is called by, the text and numbers
it uses, the data it reads and writes, and, for the harder ones, reading through what the code does. Each table row
is one function: `| address | name | what it does |`. Names are ours (the game ships without them), except class
names, which the game itself carries (see [classes.md](classes.md)). `tools/progress.py` counts a function as
understood and documented when its address is in the first column of a row here. `tools/describe.py` prints what a
function touches, which is where most of these start.

- [classes.md](classes.md): every class the game describes to itself, with its constructor and saved fields
  (generated by `tools/classes.py`)
- [library.md](library.md): Microsoft code linked into the exe (not counted as game code)
- [rendering.md](rendering.md): the graphics engine and what the game draws with it
- [gui.md](gui.md): windows, dialogs and menus
- [rides.md](rides.md): rides, their cars and trains
- [guests.md](guests.md): guests
- [park.md](park.md): the park as a whole (rating, finances, scenario)
- [animals.md](animals.md): animals (Wild!)
- [effects.md](effects.md): water, fireworks, lasers, particles
- [startup-tables.md](startup-tables.md): tables the game fills in when it starts
- [engine.md](engine.md): the rest of Frontier's engine (start-up, resources, files, parsing)
